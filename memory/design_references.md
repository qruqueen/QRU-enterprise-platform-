# QRU Design Intelligence — Reference Library

Founder-submitted references. Usable across ALL QRU design production (STD-DESIGN-0001 QRU Visual
Manufacturing Standard™ — one governed visual family, many product recipes). All customer-facing text,
numbers, citations are machine-rendered from verified Knowledge Records; AI art is decorative/composited only.

## Governed poster/card archetypes (implemented in poster_studio.py)
- process-formula-v1 — Process / Formula Poster (e.g. "The QRU Learning Formula")
- data-comparison-v1 — Data Comparison Poster (e.g. "Financial Health Card", IMF-cited)
- scorecard-grid-v1 — Scorecard Grid (e.g. "GDP Scorecard")
- illustrated-learning-v1 — Illustrated Learning Poster (e.g. "Welcome to QRU")
- decoder-v1 — Multi-Section Decoder (e.g. "Alzheimer's Decoder")
- knowledge-card-v1 — QRU Knowledge Card™ / Quick Card™ (term, plain + pro definition, analogy,
  chart clue, real-life clues, challenge, memory sentence, category flow, tags) — light theme
