# EPI-002 Runbook

1. Unzip this package.
2. Upload/copy the files into your GitHub repository.
3. Run `npm install`.
4. Run `npm run build`.
5. Run `npm run test`.
6. Run `npm run start:dev`.
7. Open `http://localhost:3000/health`.

If you get errors, paste the terminal output back into ChatGPT for repair.
